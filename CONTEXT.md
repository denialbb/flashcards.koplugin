# Flashcard Study

Extracts question-and-answer pairs from Markdown study notes and manages interactive review quizzes on the device.

## Language

**Flashcard**:
An individual study item consisting of a question prompt and its corresponding answer text.
_Avoid_: Card, Q&A pair, question item

**Theme**:
A topical category of flashcards derived from a directory or note hierarchy.
_Avoid_: Subject, category, topic folder

**Deck**:
An assembled sequence of flashcards selected for a study session.
_Avoid_: Card set, study group, stack, flashcard deck

**Quiz Session**:
An active review flow presenting flashcards for recall and scoring.
_Avoid_: Test, review run, practice session

**Recall Rating**:
The user evaluation of memory recall for a presented flashcard.
_Avoid_: Score, grade, card rating, review state

**Missed Deck**:
The subset of flashcards flagged as incorrectly recalled during a quiz session for targeted re-testing.
_Avoid_: Review set, failed cards, retry list
